# Visual Bible — The Last Arrow

**Core Metaphor**: 2D combat arena with strong character identity and online/local play. "The last arrow" suggests final, decisive, skillful combat — a duel or small-team battle where every action matters. Already has strong character art foundation.

**Emotional Promise**: Satisfying, personality-driven 2D fighting with real competitive depth and beautiful characters.

**Visual DNA Keywords**: Strong character silhouettes and personality, clean 2D combat readability, decisive moments (the "last arrow"), bot playtesting as part of the visual story, Unity 2D craft.

**Color System**:
- Strong, character-driven palette
- High readability for combat (important in 2D fighters)
- Dramatic but not noisy

**Typography Direction**: Bold, game title feel.

**Audience & Cultural Notes**: Players who love 2D combat prototypes that have soul and are being actively developed with bots and online focus.

**Forbidden Styles**:
- Generic 3D realistic fighter
- Low-effort pixel art (the characters already have strong identity)

## Reference Assets

Logo and key art should celebrate the existing character designs while giving a strong "The Last Arrow" title treatment — decisive, elegant, combat-focused.
